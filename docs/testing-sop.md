# Fullscreen Time — 手动测试 SOP

> 适用分支：`refactoring`
> 适用版本：1.0（refactoring 修复完成版）
> 测试类型：Chrome 扩展手动验收（无自动化测试框架）
> 目标：覆盖本轮全部修复项，并回归原有功能。

## 1. 测试前准备

### 1.1 环境

- Chrome / Edge（Chromium）**114 或更高**（原生 video 全屏依赖 Popover API）。
- Windows / macOS / Linux 任一；如有条件，额外覆盖 macOS（`Meta` 快捷键）与触摸设备/DevTools 触摸模拟。
- Node.js 22+、pnpm。

### 1.2 构建与加载

```bash
pnpm install
pnpm run build-dev      # 调试用，保留 source map
pnpm run build-prod     # 验收用，压缩、无 source map
```

1. 打开 `chrome://extensions`。
2. 开启“开发者模式”。
3. “加载已解压的扩展程序” → 选择仓库的 `extension/` 目录。
4. 记录扩展版本与 Chrome 版本。

> 每次修改 `src/` 后必须重新构建；`extension/content.js` 是提交到仓库的构建产物。

### 1.3 重置测试状态

在扩展的 Service Worker 控制台（`chrome://extensions` → 该扩展 → “Service Worker”）执行：

```js
chrome.storage.sync.clear();
```

然后重新加载扩展，并**刷新所有已打开的测试页面**。仅重载扩展不会替换已注入到旧标签页的内容脚本；不刷新就不是真正的全新状态。这样才能验证“全新安装”的默认行为。

### 1.4 测试页面

| 用途 | 页面 |
|---|---|
| 原生 `<video>` 全屏 | `testpage/index.html`（仓库内测试页；本地打开或 `python -m http.server`） |
| 播放器容器全屏 | YouTube / Bilibili 等站点 |
| 无视频元素全屏 | 任意图片页面，右键图片 → 在全屏中查看；或 `<div>` 全屏测试页 |
| iframe 播放器 | 带嵌入播放器的页面（如站点嵌入 YouTube iframe） |
| 直播 | 任意直播页面（duration 为 Infinity） |
| 动态视频/SPA | YouTube 站内跳转、B 站切换视频 |

建议同时打开 DevTools Console 与 Network（筛选 `_locales`），记录错误与语言包请求。

## 4. 已知限制（不是缺陷，验收时请记录）

1. **原生 `<video>` 元素全屏**使用 `popover="manual"` 置顶，主要用于显示。部分 Chrome 版本下浮层上的指针命中测试可能不稳定，因此：
   - 关闭/布局优先使用 `F10` / `F9`；
   - 关闭按钮为“尽力可点”，拖拽在该模式下不启用。
2. `Ctrl+W`、`Ctrl+T` 等浏览器保留键无法被页面拦截；录键器会拒绝绑定。
3. 非视频的 iframe/embed/object 全屏由子框架接管，可能不显示时钟；文案已注明。
4. `F11` 浏览器全屏判断基于视口尺寸近似（±2px），缩放、DPI、任务栏、多显示器可能影响识别。
5. iframe 全屏时，若键盘焦点仍在顶层页面，`F10` 可能无效；将焦点置于 iframe/视频区域后测试。
6. 页面 CSP 可能阻止内容脚本注入 `<style>`；若发现浮层无样式，请记录页面 URL 与 CSP。
7. 浏览器全屏（F11）下的 dismiss 提示依赖 3 秒超时或窗口尺寸变化收起。

## 5. 验收标准

- 冒烟 S1–S10 全部通过。
- B 组（全屏渲染）与 D 组（快捷键）无 P0/P1 失败。
- 控制台无未捕获异常、无调试日志。
- 语言切换后无原始 key、无空白首屏。
- `pnpm run build-prod` 产物可正常加载，且为压缩版本。
- 已知限制之外，没有新增回归。
