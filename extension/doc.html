📺 Fullscreen Time Extension

功能介绍

这是一个浏览器扩展，用于在视频全屏时显示当前播放时间和系统时间。

  • 自动检测页面中的视频元素
  • 在视频全屏时显示时间信息
  • 显示格式：当前时间 / 总时长 | 系统时间
  • 支持自定义显示设置

如何使用

  1. 打开任何包含视频的网页（如 YouTube、Bilibili 等）
  2. 点击视频进入全屏模式
  3. 时间信息会自动显示在屏幕顶部中央
  4. 点击扩展图标可以打开设置面板

设置选项

在视频中显示时间： 控制是否启用时间显示功能

在全屏时显示： 控制是否只在全屏时显示时间

💡 提示： 如果时间显示没有出现，请尝试刷新页面或重新加载扩展。

技术栈

  • Webpack - 模块打包工具
  • Chrome Extension Manifest V3
  • ES6 Modules
  • Chrome Storage API
