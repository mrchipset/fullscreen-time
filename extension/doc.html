Fullscreen Time

A browser extension that displays playback time and system time when videos or the browser enter fullscreen.

Features

  • Auto-detect video elements on the page
  • Display time info during video fullscreen
  • Format: Current / Duration | System Time
  • Customizable display settings

How to Use

  1. Open any webpage containing a video (YouTube, Bilibili, etc.)
  2. Click the video to enter fullscreen
  3. The clock appears at the top center by default
  4. Click the extension icon to open the settings panel

Settings

Video overlay: Shows playback time and the clock over fullscreen video.

Browser / other fullscreen overlay: Shows the clock in browser fullscreen or in fullscreen on page content without a video. Embedded/iframe players are handled inside the frame; a non-video embed may not show a clock. It never stacks with the video overlay.

Tip: If the time display doesn't appear, try refreshing the page or reloading the extension.

Tech Stack

  • Webpack - Module Bundler
  • Chrome Extension Manifest V3
  • ES6 Modules
  • Chrome Storage API
